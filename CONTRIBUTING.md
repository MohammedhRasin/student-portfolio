# Portfolio Update Guidelines

This is a personal portfolio. Updates should be accurate, clear, and supported by evidence.

1. Use one Markdown file per project or major achievement.
2. Explain your own contribution separately from team outcomes.
3. Link to public demos, repositories, or credential verification pages.
4. Do not publish private data, API keys, passwords, or confidential college/client material.
5. Use consistent dates (`YYYY-MM-DD`) and descriptive file names.
6. Review spelling, links, and screenshots before committing.
